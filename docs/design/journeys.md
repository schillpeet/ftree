# User journeys

## New user without a tree

1. Signs in (invited/allowed address) and is not assigned to any tree.
2. Sees the welcome card over the blurred scene, name prefilled; optionally adds a birth year.
3. "Baum pflanzen" creates the tree "Familie <Nachname>" with the user as the first person.
4. Camera settles on the user's card; the intro tour starts (skippable).
5. Dashed slots invite the first relatives; mother, then father in one flow.
- Goal: first own card in under 30 seconds, first relative within the first minute.
- Alternatives on the card: GEDCOM import, or the example family first.

## Invited user

1. Opens the invitation link; sees who invited them and to which tree, with a short summary.
2. If the invitation names a member, the card shows "Du hängst schon im Baum als …" with "Nicht ich".
3. "Einladung annehmen" opens the tree focused on their own card, with a small task list.
4. The intro tour runs once.
- Goal: they contribute something (photo, date fix, own branch) in the first session.

## Returning user

1. `/` goes straight to their last tree; the camera flies to their own card.
2. Dock for the main actions, header for family, theme, language, menu.
3. Selecting a person highlights their lineage and shows the person panel; "+" slots show what is missing.
- Goal: no hunting through menus; any relative is two clicks and a name away.

## Signed-out visitor

1. `/` shows the landing page.
2. "Beispielfamilie ansehen" opens a read-only example tree; "Anmelden" / "Baum anlegen" start sign-in.
